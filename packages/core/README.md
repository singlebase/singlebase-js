# @singlebase/core

Internal kernel shared by the Singlebase JavaScript packages: the RPC transport,
the request dispatcher, errors, storage adapters and the page client registry.

You don't install this directly. Use
[`@singlebase/singlebase-sdk`](https://www.npmjs.com/package/@singlebase/singlebase-sdk)
for the client, or [`@singlebase/elements`](https://www.npmjs.com/package/@singlebase/elements)
for the web components. Both depend on it.

Documentation: https://github.com/singlebase/singlebase-js
